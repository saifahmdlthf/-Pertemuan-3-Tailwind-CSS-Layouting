Penjelasan Materi Praktikum

Berikut penjelasan teknik layouting CSS modern yang digunakan pada website ARSDev.

No. Materi Fungsi Implementasi
1 Flexbox Mengatur posisi elemen secara fleksibel. Navbar dan Hero Section.
2 CSS Grid Menyusun elemen dalam baris dan kolom. Kartu layanan website.
3 Responsive Design Menyesuaikan tampilan dengan ukuran layar. Tampilan HP, tablet, dan desktop.
4 Media Query Mengatur CSS berdasarkan lebar layar. @media (min-width: 768px).
